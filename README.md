# Anaqia: Everything You Love

Anaqia অনলাইন মার্কেটপ্লেসের ওয়েবসাইট (ফ্রন্টএন্ড)। ডিজাইন ডার্ক ফিউচারিস্টিক, রঙ বেগুনি-গোলাপি। বাংলা/ইংরেজি দুই ভাষা আর টাকায় (৳) দাম।

## পেজসমূহ
- হোম: হিরো, ক্যাটাগরি, ফ্ল্যাশ ডিল (কাউন্টডাউনসহ), কালেকশন, বাছাই করা পণ্য, ট্রেন্ডিং, অফার, রিভিউ, নিউজলেটার
- শপ: ৭টি ক্যাটাগরিতে ৫৬টি পণ্য, ক্যাটাগরি ফিল্টার, দামের সীমা, সাজানো, সার্চ (`#/shop`)
- পণ্যের পেজ: সাইজ, পরিমাণ, উইশলিস্ট, সম্পর্কিত পণ্য
- কার্ট: পরিমাণ বদলানো, কুপন (`WELCOME20` = ২০% ছাড়, ন্যূনতম ৳১,০০০; `ANAQIA100` = ৳১০০ ছাড়)
- চেকআউট: ডেলিভারির তথ্য, ঢাকার ভেতরে/বাইরে চার্জ, ক্যাশ অন ডেলিভারি, বিকাশ, নগদ, কার্ড
- অর্ডার ট্র্যাকিং, লগইন/রেজিস্টার, আমার অ্যাকাউন্ট, উইশলিস্ট, যোগাযোগ

> এটি ডেমো স্টোর: কোনো আসল পেমেন্ট নেওয়া হয় না। কার্ট, অর্ডার আর অ্যাকাউন্ট ব্রাউজারে (localStorage) সংরক্ষিত থাকে।

## চালানো
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ ফোল্ডারে প্রোডাকশন ফাইল
```

## অনলাইনে তোলা (ফ্রি)
Vercel বা Netlify-তে এই রিপোজিটরি যুক্ত করুন। Build command: `npm run build`, Output folder: `dist`।

## পরিবর্তন করা
- পণ্য, দাম, ক্যাটাগরি, কুপন, ডেলিভারি চার্জ: `src/data/products.js`
- আসল ছবি: ঠিক নামের ছবি `public/images/products/`, `categories/` বা `site/` ফোল্ডারে রাখলেই নিজে থেকে দেখাবে। সব ফাইলের নাম ও ছবি তৈরির প্রম্পট: `docs/IMAGE-PROMPTS.md`
- সব লেখা (বাংলা ও ইংরেজি): `src/i18n.js`
- রঙ ও ডিজাইন: `src/styles.css` এর শুরুর `:root` অংশ
- লোগো: `src/components/Logo.jsx` ও `public/favicon.svg`

## প্রযুক্তি
React 18 + Vite + React Router (HashRouter, তাই যেকোনো স্ট্যাটিক হোস্টে চলে)।
